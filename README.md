# Northstar Cloud Documentation

**A technical documentation portfolio project demonstrating end-user SaaS documentation, information architecture, editorial governance, and AI-assisted content development.**

[View Published Documentation](https://docs.elizalenz.com) | [Professional Portfolio](https://elizalenz.com)

## Project Overview

Northstar Cloud is a fictional B2B SaaS administration platform created to demonstrate the planning, development, and maintenance of a structured product documentation knowledge base.

The platform includes user and team management, roles and permissions, authentication, notifications, reporting, and integrations.

The documentation reflects real-world SaaS documentation practices, with an emphasis on usability, consistency, accuracy, and maintainability.

## Documentation Approach

**Information Architecture**

Organizing content around user tasks and workflows, with consistent navigation, terminology, and page structure.

**Editorial Standards**

Applying consistent formatting, procedural instructions, screenshots, callouts, and documentation conventions to improve readability and usability.

**Documentation Governance**

Recording editorial decisions and establishing repeatable content standards to support consistency, scalability, and future maintenance.

**AI-Assisted Documentation**

Using AI tools to support drafting, content development, and iterative refinement while retaining human oversight of information architecture, accuracy, editorial decisions, and final presentation.

## Project Scope

Northstar Cloud is a fictional product developed for portfolio purposes. Its product specifications, workflows, interfaces, and documentation examples are illustrative rather than representations of a commercially available application.

The project demonstrates professional technical writing, documentation management, editorial judgment, and the application of AI-assisted workflows to structured content development.
